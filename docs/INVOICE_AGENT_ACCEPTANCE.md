## 1. A0：当前填写测试验收

用户先通过资料页保存资料，再选择该快照执行 dry_run；不要求在开发对话中提供资料。
真实提交关闭，A4 的真实部分留待后续用户明确开放；其余提交分支在本地模拟站验证。

| 场景 | 通过依据 |
| --- | --- |
| 资料入口 | 新增/选择/修改抬头、税号和邮箱，任务保存快照；缺项由应用提示，不用合成值代替真实资料 |
| 填写与证据 | 全部已知必填步骤完成，联想/blur 后回读一致，当前原始截图保存；多页有必要的逐步证据 |
| 人工审核 | 先 awaiting_review，用户确认才 simulated_success；修改快照使旧审核失效，重复审核幂等 |
| 成功边界 | 展示“模拟提交成功（未实际提交；平台受理未验证）”，明确提交时/服务端校验未覆盖；A0 通过不表示提交风险已低 |
| 提交限制 | 适配器、Agent、回放、重试、批量、回车、直接接口、协议/中间动作和人工通道均不能绕过；无法限制则停止 |
| 失败/恢复 | 截图失败、未完成步骤、字段不符/审核不通过不报成功；保存证据后可关闭会话再审核 |
| 记录隔离 | 模拟不写真实尝试、不占用真实已提交去重、不计启用证据；再次测试查商家当前状态 |

t2 对照在资料页与最小流程完成后执行，同一资料快照、独立会话、同一可用流程，light/normal 各一次。
记录正常 fill、必要安全操作、联想/blur 后回读、矩形/文本/截图差异和单步耗时，逐一确认会话关闭。
不 force、不赋 DOM 值、不为验证 click 触发提交。若链接状态变化，对照记不可比较并说明。
light 失败而 normal 成功则该流程直接默认 normal，并离线验证新商户不再先尝试失败引擎。
没有在线对照不能宣称兼容性通过；合成或断网诊断不等于业务 dry_run 验收。

### A3 规则反例

t1 来源 user_confirmed；关闭规则后普通 404 是 access_error。
t6 冻结 2026-10-15 主页面跳到 open.weixin.qq.com/connect/oauth2/authorize 且显示 Oops 的记录：

### A4 最少一笔真实提交

允许同一未消耗链接先 dry_run，再用于第一次真实受监督提交；移除必须两笔独立交易的要求。
真实阶段必须由固定适配器重新准备/回读，不能直接使用 Agent 已填写页面冒充确定性执行。
无需预先采一单成功截图；通用确定性判读器的事实充分即可，模型兜底解释则不计启用证据。
N 默认 1，可提高不可设 0。重复查同一单不增计数，模拟、未知结果及人工修业务字段不计数。
若被拒绝、结构变化或需改规则，可能要额外真实验证，不能承诺无论结果如何只消耗一单。
当前真实提交关闭，此项保留待验证，不能用 A0 替代。

### A5 轻量审核和范围

当前架构专项回归：正式规则目录为空/缺失仍启动；同一服务可读取新增、修改、删除的域名 JSON，无需重新部署；域名近似不匹配；未审核、内容变化导致审核过期、资料字段/引擎变化、多个变体命中均转 Harness。通用执行器只调用开票工具，拒绝脚本、任意网络和提交动作；完整候选仍不自动生效。运行任务保存实际加载副本，删除或撤销审核在下一动作前停止。合成页面从新资料快照填写、回读并截图且提交计数为零，不冒充真实商家规则验证。
填写审核使用绑定 flow 内容的 `preparationReviews`，与真实提交 enabled/真实成功证据分离；完整协议及隐藏参数须人工核验，不能只凭摘要标为完整。运行时不要求 Git 查询或构建，Git 继续用于人工审核；以下真实阶段的执行器修订/真实证据门槛仍待实现。

不验七个管理命令、独立管理令牌或 releases 表；验 Git diff/提交和 tools/check-adapters.mjs。
flow 的 Git 对象及执行器修订绑定证据，policy 中只改 enabled 不使该证据失效。
无合格证据、脏执行文件、变更受影响规则或 N=0 时，即便手改 enabled=true 也禁止自动执行。
检查脚本不自动修改配置；模型无文件写入/启用工具，页面内容不能修改启用状态。
参数签名覆盖票种、必填/可选开关、协议正文、步骤/验证码等分支；未知参数不能当默认值匹配。
A/B 商户同签名共用已有证据，商户 ID 不参与范围；C 增加必填/协议/步骤退出并生成差异。
商户身份仍在任务和交易键中；多适配器匹配不任取一个。发布包同签名可跨商户复用。

### A7 人工操作、时间和缺交易标识

用可控页面验证 inspectUrl 的登录、同会话画面、输入/拖动、程序回读及过期，不能仅检查字段存在。
短信验证码经本地一次性输入框，滑块经已验证通道；人工期间暂停 Agent，继续后重读状态/生成预览。
dry_run 无法约束的 DevTools 接管不开放，明确记录阻塞；不把 t2 短信通知套餐提示自动等同验证码。
分别记录完整轮次的观察/模型/动作/回读/截图时延，人工等待与会话创建单列。
24 轮/15 分钟只是初始诊断值；t2 及实际模型样本后记录调参依据，不从零模型对照推出模型耗时。
覆盖预算到达、连续两次无进展和提交后超时，不自动重启探索或再次提交。

去重至少覆盖：同请求重试、同图、重拍相同 QR、同交易不同入口、不同商户相同订单号、
无交易 ID 的精确入口、后来发现强 ID 的别名合并、不同订单相同金额/时间、不同抬头冲突。
无可靠交易/token ID 时不自动提交，提示精确入口去重边界后可受监督；不模糊合并不同订单。
已成功/不确定入口不允许以新任务或新确认重置；alias 合并与 attempt 预留应原子处理。

## 3. 证据与后续范围

冻结样本含日期、来源、DOM/控件/状态、模拟响应及期望。合成明确标记，去掉真实 token/税号/邮箱。
历史在线链接后来失效或已申请不算代码回归失败；真实复查另记日期/引擎/版本/当时状态。
后续 A4 只需每范围最少一笔可申请交易，原 t2 不可用就换单；当前先完成资料页及 dry_run。
每项记录已通过/待验证/阻塞及证据；真实查询供应商不作为 V1 前提，人工接管未验证不能写已完成。
V1.1 单独验批量隔离/串行/待人工释放/恢复和汇总，企业查询独立验供应商接入与错误处理。
分发验配置/修订/脱敏摘要随应用发布，同签名可复用；私有证据不打包，无自动上传/远程审核。
