# v0.4.5 实现与验证记录

日期：2026-10-16。当前交付为对话式填写测试版，不宣称完整真实开票验收通过。

## 已实现

- 2026-10-16 新增填写前的引擎复核：light 出现通用错误、空白、HTTP/导航/订单读取异常或微信客户端限制时，先关闭 light，再从原入口以 normal 复核一次；两次均验证提交拦截。normal 可读取才进入现有规则/Harness，实际引擎贯穿规则选择、模型执行和候选导出；没有填写后自动重试或扩大网络权限。已开票、已有申请、失效、真实零金额和用户确认的客户端入口不触发复核。每任务保存 engine-check.json、分引擎观察和截图，不以复核通过代替填写回读/最终截图审核，也不自动发布引擎偏好。
- 云端会话统一发送 `Accept-Language: zh-CN,zh;q=0.9`，避免微信授权错误页的语言差异被当成引擎故障；保留精确微信授权地址的客户端限制判断，不从 Oops 文案推断根因。
- 2026-10-16 修复 t5 美团小票入口读取误拦截：只允许 `process/queryReceiptQrCode` 的精确 POST、当前原小票链接和已观察的四字段桌面参数（url/appChannel/env/identifyToken），以及此入口使用的特定 CDN 版本化 JS/CSS fetch 读取。其他订单、额外参数、未核验身份环境、申请/发送邮件/详情接口仍拒绝，未开放整站或全部 POST。服务出错/网络异常弹窗在填写前识别，若伴随未知业务接口拦截则明确记录 `network_read_blocked`，不称为商家服务端故障。

- Windows 后台 Harness 启动修复：固定 SDK `0.2.1-alpha.4` 的 transport spawn 补齐 `windowsHide: true`，主对话与业务 Harness 共用；postinstall/prestart/predev 自动校验并应用一行兼容补丁，版本/启动代码变化时拒绝静默替换。不改变 stdio、环境隔离、会话恢复或进程关闭协议。

- 纯对话首页、会话列表、文字/图片/文本附件输入，资料/记忆、任务和截图卡片。
- 真正的 DeepSeek Harness 主对话 Agent；qwen3.8-max，多轮固定会话及关闭后恢复。
- 主对话与业务执行共用 Harness 包装；模型真实调用、上下文整理调用均通过流事件统计。
- SQLite 持久 conversations/messages/memories，共享 userId=local 资料和偏好；任务/附件归属 conversationId。
- 资料新增/编辑/默认项/删除、长期偏好与别名写入和遗忘均通过聊天工具，写入后才反馈结果。
- 原始资料有来源约束，税号不能由自由记忆编造；“这次”覆盖消费后清除，不修改全局默认。
- 任务历史作为只读经历记录，模型发起开票前可检索；已审核完整规则匹配直执行，其余业务 Harness 分析。
- 2026-10-16 规则架构调整：`src/rules/` 提供域名 JSON 加载、严格动作/范围校验、通用工具执行和候选导出；`src/adapters/<域名>/` 仅保存 flow/policy，不逐站写专用代码。规则缺失/为空、热增删改、未审核/过期/歧义均安全处理；运行时保存规则快照，变更在下一动作前停止。见 [域名规则架构](DYNAMIC_RULES.md)。

- 历史对话支持删除，先停止回复/任务再清理该对话消息、附件、结果及模型会话；共享资料/偏好保留。
